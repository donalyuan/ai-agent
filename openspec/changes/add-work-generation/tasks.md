# 作品生成未来实施任务

> 本轮只定义规格。以下任务全部留待后续实施。

## 1. 协议核验与领域模型

- [ ] 1.1 对照实施时有效的 Seedance 官方文档核验创建、查询、取消、素材、提示词、输出和原声协议。
- [ ] 1.2 先补领域失败测试，再实现 Work、WorkVersion、WorkPlan、规划版本和 WorkGenerationRun。
- [ ] 1.3 实现运行输入、模型、能力、音色、提示词、时间轴和参数不可变快照。
- [ ] 1.4 实现规划版本与确认幂等约束，输入变化使旧计划失效。

## 2. 作品 Agent 与计划

- [ ] 2.1 实现 `work` Agent adapter 和可见对话/工具步骤审计。
- [ ] 2.2 接入完整主画面 manifest、脚本、旁白和已有声音素材。
- [ ] 2.3 实现方案 LLM、视频、TTS 独立选择、默认预选和 Agent 只推荐。
- [ ] 2.4 实现全片提示词、分段提示词编辑及运行中修改进入下一版草稿。

## 3. 输出参数与 Seedance 分段

- [ ] 3.1 实现 `15/30/45/60秒`、`4~60秒` 和跟随配音策略。
- [ ] 3.2 实现动态比例、分辨率、原声能力和模型切换重新校验。
- [ ] 3.3 先补边界测试，再实现 4~15 秒、9 图、提示词限制和尾段重分配算法。
- [ ] 3.4 实现无法形成合法分段的结构化阻断响应。
- [ ] 3.5 实现 Seedance fake provider contract 和作品级一次提交。

## 4. 声音、字幕与 FFmpeg

- [ ] 4.1 实现三种声音模式和按模型能力显示。
- [ ] 4.2 实现已有 BGM、环境音和动作音效多轨时间轴校验。
- [ ] 4.3 以媒体 fixture 先补失败测试，再实现拼接、混音、ducking 和时长处理。
- [ ] 4.4 实现默认字幕烧录、关闭烧录和独立 SRT。
- [ ] 4.5 验证输出为 `MP4(H.264) + AAC`，输入缺失不得伪成功。

## 5. 页面与全链路验收

- [ ] 5.1 更新 Pencil 作品生成原型并取得用户明确确认。
- [ ] 5.2 实现 Agent 对话、镜头清单、参数、计划预览和最终确认。
- [ ] 5.3 实现任务数、视频秒数、TTS 字符数、ASR 时长展示，确认无金额字段。
- [ ] 5.4 补齐领域、API、provider、Worker、FFmpeg、前端和 E2E。
- [ ] 5.5 经用户单独许可后执行最小受控真实 Seedance/TTS/ASR 验证。
- [ ] 5.6 运行 OpenSpec 和全量相关验证后申请归档。
