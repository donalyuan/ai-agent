## ADDED Requirements

### Requirement: 项目规则以可验证事实为依据
项目助手规则 MUST 保留简体中文沟通、项目记忆读取与维护、事实优先、OpenSpec、验证及 Git 授权边界。规则 MUST NOT 将当前仓库无证据支持的业务、数据、第三方平台或宿主机状态写成项目事实或强制前置条件。

#### Scenario: 仓库未定义技术栈
- **WHEN** 助手需要处理当前没有代码、配置或需求可证实的技术栈或外部集成
- **THEN** 助手将其标为待确认，并且不从已删除规则或宿主机状态推断为项目事实

#### Scenario: 维护项目规则
- **WHEN** 助手更新项目规则或当前交接
- **THEN** 助手仅保留已确认且后续可复用的信息，并避免记录绝对设备路径、凭据和临时探索

### Requirement: 任务按当前可用 skill 路由
当对应 skill 在当前会话可用时，项目助手 MUST 在新建或重构 UI 时使用 `frontend-design`，在需要浏览器交互或端到端检查时使用 `playwright`。执行当前项目前端开发、调试或验证任务时，助手 MAY 自动截取当前项目的浏览器页面或应用窗口；浏览器页面截图 MUST 优先使用 `playwright` 的工具内截图，代理自查截图 MUST 仅保存于临时目录。整个桌面、其他应用、其他项目或无关内容的截图，即使在前端任务中，也不在自动授权范围内；非前端任务的任何截图以及其他所有范围外截图，助手 MUST 事前向用户索要明确授权。助手不得将 skill 的当前安装状态表述为跨设备仓库事实。

#### Scenario: 新建 UI
- **WHEN** 助手在当前会话中新增或重构 UI，且 `frontend-design` 可用
- **THEN** 助手使用 `frontend-design` 指导该 UI 工作

#### Scenario: 浏览器端到端检查
- **WHEN** 助手需要执行浏览器交互或端到端检查，且 `playwright` 可用
- **THEN** 助手使用 `playwright` 执行该检查

#### Scenario: 当前前端任务中的项目页面截图
- **WHEN** 助手正在执行当前项目前端开发、调试或验证任务，并需要截取当前项目的浏览器页面或应用窗口
- **THEN** 助手可以自动截图；浏览器页面优先使用 `playwright` 的工具内截图，代理自查截图仅保存于临时目录

#### Scenario: 前端任务中的范围外截图
- **WHEN** 前端任务需要截取整个桌面、其他应用、其他项目或无关内容
- **THEN** 助手必须先向用户索要明确授权，未获授权不得截图

#### Scenario: 非前端任务截图
- **WHEN** 非前端任务涉及任何截图且用户没有明确授权
- **THEN** 助手必须先向用户索要明确授权，未获授权不得截图

### Requirement: 当前交接反映规则状态
项目的当前交接 MUST 记录已完成的规则与能力对齐、相关验证及仍待确认的项目范围，同时 MUST NOT 将该次整理的临时过程写成长期事实。

#### Scenario: 规则整理完成
- **WHEN** 规则与能力对齐变更完成
- **THEN** `HANDOFF.md` 说明当前规则路由、验证结果和仍待确认的产品与技术栈信息
