# rank-topic-groups-for-script-production Proposal

## 背景

内容策略模块已经具备选题池、历史生成、补充批次归组和主题组 AI 评审快照。当前“历史生成”仍主要按时间展示主题组，运营人员需要逐个进入主题组查看评审分层，才能判断哪些主题组最适合立刻进入脚本创作。

用户已确认本轮目标不是泛化质量排名，而是“选出最值得立刻生成脚本的主题组”。因此排名必须围绕脚本产出优先级设计，优先暴露已有高质量、低风险、脚本化路径清晰的主题组和选题候选。

## 目标

1. 为历史生成页新增主题组“脚本产出优先级排名”能力。
2. 默认按脚本优先级展示主题组，同时保留按时间排序入口。
3. 每个主题组展示可解释的优先级状态、分数、关键指标和推荐脚本候选。
4. 仅基于已有选题、生成批次和最新成功评审快照计算排名，不在列表加载时触发额外 AI 调用。
5. 没有评审或评审已过期的主题组必须标记为待评审或需重新评审，不得被误排为高优先级。
6. 排名只作为决策辅助，不得自动确认、归档、删除选题或改变 `ContentTopic.status`。

## 非目标

1. 不实现跨项目、跨账号的全局内容战略排序。
2. 不在历史列表加载时调用 LLM 做跨主题组重新评审。
3. 不自动批量确认、归档、移除或生成脚本。
4. 不改变补充批次归入原始主题组的语义。
5. 不覆盖移动端原型、移动端适配或移动端验收。

## 影响范围

- 后端新增或扩展主题组 summary 读模型，计算脚本产出优先级。
- API 需要返回主题组级排名字段、评审新鲜度、关键指标和推荐候选。
- `apps/video-agent` 历史生成页左侧主题组列表新增排序切换、优先级状态和解释性指标。
- 当前选题池继续按主题组上下文展示评审分层，不因排名自动改变状态。
- OpenSpec、项目记忆、Pencil 原型和相关测试需要同步更新。
