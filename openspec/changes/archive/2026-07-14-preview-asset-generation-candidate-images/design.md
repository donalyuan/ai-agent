## Context

素材库页面已经实现图片大图预览，包括遮罩、关闭按钮、Escape、50%-200% 缩放和焦点恢复。素材生成页的候选卡片目前只渲染 `<img>` 缩略图，AI 图片候选即使已有稳定素材 URL 也无法查看完整图片。

本次变更已经通过 Pencil 原型确认，页面归属为 `素材管理 / 素材生成`，不得误归到素材库页面。

## Goals / Non-Goals

**Goals:**

- 仅为素材生成页 AI 图片候选区中具有有效预览 URL 的缩略图提供可访问的大图入口。
- 让素材库和素材生成页复用同一弹层结构、缩放边界和关闭行为。
- 保持选择、排除、任务状态和费用相关逻辑不变。

**Non-Goals:**

- 不扩大到旧素材候选、当前主素材、视频或失败占位。
- 不新增 API、数据库字段、文件处理或图片生成调用。
- 不提供下载、旋转、拖拽或候选切换功能。

## Decisions

### 抽取共享图片预览弹层

将素材库现有大图弹层抽取为无业务归属的共享 React 组件，由调用方传入图片 URL、标题、副标题和关闭回调。共享组件内部管理缩放比例和 Escape 监听，避免两处复制相同交互后产生行为漂移。

替代方案是在 `AssetCandidatePanel` 内复制弹层实现。该方案改动文件更少，但会重复缩放边界、键盘监听和遮罩关闭逻辑，后续修复必须同步两处，因此不采用。

### 候选区显式开启预览能力

`CandidateCard` 默认不可预览，只有渲染 AI 图片候选区时显式传入预览回调。卡片仅在 `candidatePreviewUrl` 返回有效 URL 时把缩略图渲染为按钮。

这样不会因为 `CandidateCard` 被当前主素材和旧素材共同复用而意外扩大范围，也能保证失败、等待生成和无 URL 候选保持原样。

### 由调用方恢复触发器焦点

共享弹层负责关闭事件，页面负责保存最后一次点击的缩略图按钮并在关闭后恢复焦点。素材生成页存在多个候选触发器，必须保存实际触发元素，不能使用固定单一 ref。

## Risks / Trade-offs

- [共享组件抽取可能影响素材库既有预览] -> 保留现有 DOM 语义和 class，并运行素材库既有预览回归测试。
- [候选刷新后触发元素可能卸载] -> 焦点恢复使用可选元素引用，元素仍连接时才聚焦，不影响关闭弹层。
- [大图加载失败] -> 浏览器保留图片原生失败表现；本次不改变候选 URL 的生成与有效性判断。

## Migration Plan

1. 抽取并接入共享大图弹层，保持素材库行为不变。
2. 在 AI 图片候选区启用缩略图按钮和弹层状态。
3. 运行前端单测与素材生成 E2E 定向验证。

回滚时移除素材生成入口并把共享组件内容内联回素材库，不涉及数据迁移。
