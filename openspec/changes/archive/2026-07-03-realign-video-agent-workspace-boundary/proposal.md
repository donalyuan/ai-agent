## Why

当前 `script-agent-workspace` 已经实现“生成脚本 -> 查看分镜 -> 更新状态”的生产流程，并且页面壳层预留选题、脚本、素材、视频、发布、优化六个智能体入口。该页面不再只是验证脚本 API 的临时后台页，而是 `video-agent` 视频内容生产工作台的雏形。

继续把正式生产工作台放在 `admin/` 会混淆两个长期边界：`admin/` 应作为平台管理后台，承载用户、权限、模型、工具、MCP、任务、日志、运行状态等控制面能力；`apps/video-agent/` 应作为视频内容生产业务应用，承载运营人员每天使用的选题、脚本、素材、视频、发布、优化流程。

因此需要先建立一个修正性 OpenSpec change，明确后续迁移方向和验收标准，避免在错误目录继续扩展正式业务工作台。

## What Changes

1. 明确 `apps/video-agent/` 是 `VEDIO-AGENT / 视频工作台` 的正式承载边界，负责视频生产流程。
2. 明确 `admin/` 收敛为平台管理后台，不承载日常视频内容生产页面。
3. 要求后续实现将当前 `admin/` 中的视频工作台迁移或重建到 `apps/video-agent/`，而不是废弃已有页面。
4. 要求更新 Compose、README、记忆文件、OpenSpec、测试和 Playwright 验证入口，使 `apps/video-agent` 有独立可运行前端服务。
5. 保持桌面端约束：本 change 不引入移动端原型、移动端适配或移动端验收。

## 不包含范围

1. 本 change 只定义边界修正和迁移验收，不在提案阶段直接移动代码。
2. 不改变后端脚本 API 的业务语义。
3. 不把平台管理能力迁入 `apps/video-agent/`。
4. 不重新引入项目创建或项目管理入口到脚本生产工作台。
