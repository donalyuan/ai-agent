# 作品生成任务管理 Proposal

## Why

作品一次提交会产生 LLM、TTS、字幕、多个 Seedance 分段、ASR、混音和合成步骤。仅显示一个百分比无法判断真实进度，也无法安全恢复上游任务或只重试失败节点，因此需要独立的作品生成任务管理模块。

## What Changes

- 新增 `作品生产 / 生成任务` 高密度列表和右侧分步骤详情；作品确认成功后提供“查看生成任务”直达入口并定位当前运行。
- 任务列表以“未生成 / 生成中 / 已完成”为三个主状态视图，失败或状态不确定的运行通过独立“需处理”入口展示，不伪装成正常状态。
- 展示作品版本、阶段、聚合进度、子任务状态、模型/工具、耗时、非金额资源用量、错误和结果素材。
- 取得上游任务 ID 后只查询/恢复原任务；未取得 ID 的临时错误只允许同模型自动重试一次。
- 失败时保留成功素材，只重试失败节点及必要下游步骤；人工重试前再次确认资源用量。
- 排队任务可取消；运行中按供应商真实能力决定是否可取消。
- 失败任务可从默认列表隐藏，但任务、错误和调用审计永久保留。
- 与一级菜单“工作流任务”保持边界，只管理作品生产运行。

## Capabilities

### New Capabilities

- `work-generation-task-management`: 定义作品任务列表、步骤聚合、上游恢复、节点重试、取消、隐藏和审计。

### Modified Capabilities

无。

## Impact

- 数据：未来新增运行步骤、provider attempt、租约、追踪 ID、隐藏状态和资源用量审计。
- 后端/Worker：未来实现服务端状态聚合、恢复、重试、取消和并发控制。
- 前端：未来新增高密度列表与右侧详情。
- 依赖：消费 `add-work-generation` 创建的作品运行，不创建作品内容方案。

## Non-Goals

- 不定义作品生成参数、Agent 提示词和 FFmpeg 内容逻辑。
- 不管理跨 Agent、平台 Worker、队列或系统级任务。
- 不删除失败审计，不自动跨模型或供应商。
- 不维护价格、金额或费用字段。
- 本轮只写 OpenSpec，不执行任何代码或外部任务。
