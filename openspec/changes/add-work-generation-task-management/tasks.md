# 作品生成任务管理未来实施任务

> 本轮只定义规格。以下任务全部留待后续实施。

## 1. 状态模型与数据库

- [ ] 1.1 先补状态聚合失败测试，再实现 run、step、attempt 和条件 DAG 状态。
- [ ] 1.2 新增幂等映射、单节点在途唯一约束、Worker 租约和上游身份字段。
- [ ] 1.3 实现错误分类、资源用量、结果素材和脱敏 provider 审计。

## 2. 恢复、重试与取消

- [ ] 2.1 实现取得上游任务 ID 后只恢复查询，Worker 重启不得重复提交。
- [ ] 2.2 实现提交前临时错误最多同模型重试一次，不确定提交转人工。
- [ ] 2.3 实现失败节点新 attempt、成功素材复用和必要下游重跑。
- [ ] 2.4 实现重试确认幂等、并发防重和非金额资源用量展示。
- [ ] 2.5 实现排队取消、供应商支持的运行中取消和不支持取消的明确冲突。
- [ ] 2.6 实现失败任务隐藏/查看及永久审计保留。

## 3. API 与页面

- [ ] 3.1 实现任务列表、服务端进度聚合、筛选和步骤详情 API。
- [ ] 3.2 更新 Pencil 高密度列表与右侧详情原型并取得用户明确确认。
- [ ] 3.3 实现任务列表、步骤详情、重试确认、取消和隐藏交互。
- [ ] 3.4 验证页面不混入跨 Agent 工作流任务和任何金额字段。

## 4. 验收

- [ ] 4.1 使用 fake provider 覆盖分段并行、响应丢失、Worker 重启和节点重试。
- [ ] 4.2 补齐数据库、API、Worker、前端和桌面端 E2E。
- [ ] 4.3 运行 OpenSpec 和全量相关验证后申请归档。
