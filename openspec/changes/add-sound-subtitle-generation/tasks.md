# 声音与字幕生成未来实施任务

> 本轮只定义规格。以下任务全部留待后续实施。

## 1. 协议与能力目录

- [ ] 1.1 对照实施时有效的官方文档核验 `ListSpeakers`、TTS V3 和 ASR 请求响应并建立脱敏 contract fixture。
- [ ] 1.2 先补目录同步失败测试，再实现按 `ResourceID` 分页、完整批次原子提交和下线标记。
- [ ] 1.3 实现 Admin 主动/定期同步、工作台检查更新和同步状态可观测。
- [ ] 1.4 实现模型版本化声音能力及失效选择保留但阻断生成。

## 2. Agent、TTS 与试听

- [ ] 2.1 先补声音 Agent adapter 测试，再接入统一对话 Runtime 和工具步骤审计。
- [ ] 2.2 实现 TTS V3 provider、流式校验、唯一请求 ID、`X-Tt-Logid` 和密钥脱敏。
- [ ] 2.3 实现主动试听、字符数确认、幂等、并发限制和临时错误最多一次重试。
- [ ] 2.4 实现音频落盘和素材库新增，不覆盖历史素材。

## 3. 字幕与 ASR

- [ ] 3.1 实现 TTS 字词时间戳断句、时间轴和 SRT 输出。
- [ ] 3.2 实现不支持时间戳语种的明确失败，不伪造对齐。
- [ ] 3.3 实现已有音频 ASR 任务、字幕素材和来源审计。

## 4. 页面与验收

- [ ] 4.1 更新 Pencil 双标签工作区原型并取得用户明确确认。
- [ ] 4.2 实现动态模型/音色/风格选择、声音 Agent 对话和任务状态。
- [ ] 4.3 补齐目录、provider、API、Worker、前端和桌面端 E2E。
- [ ] 4.4 经用户单独许可后执行最小受控真实 TTS/ASR 验证。
- [ ] 4.5 运行 OpenSpec 和全量相关验证后申请归档。
