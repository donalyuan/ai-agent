# 作品库管理 Proposal

## Why

生成完成后需要稳定管理成片、版本、时间轴、调用审计和后续修改。如果直接覆盖同一作品文件，将无法比较版本、复用未变化素材或追溯具体发布版本，因此需要独立的作品库与不可变版本能力。

## What Changes

- 新增 `作品生产 / 作品库`，默认缩略图网格并支持列表切换。
- 作品详情展示成片预览、多轨时间轴、版本记录、Agent 方案、调用审计和版本对比。
- 已确认或运行过的版本不可变；继续修改、局部修改和整体重生成必须派生新草稿。
- 修改前展示结构化差异、影响范围、再次调用任务和非金额资源用量，只重生成受影响节点。
- 产生过外部调用或版本产物的作品只能归档/恢复；空白未调用草稿可删除。
- 完成版本可下载 MP4、SRT、混音/可用分轨和制作包。
- 可携带明确选定版本进入发布运营，但不自动发布，发布状态不进入作品生命周期。

## Capabilities

### New Capabilities

- `work-library-management`: 定义作品浏览、详情、不可变版本、差异影响、下载、归档和发布交接。

### Modified Capabilities

无。

## Impact

- 数据：未来新增作品身份、版本、artifact、时间轴、版本来源和归档状态。
- 后端：未来新增作品查询、版本派生、影响分析、下载和发布草稿交接 API。
- 前端：未来新增网格/列表、详情、版本对比和修改工作流。
- 依赖：消费 `add-work-generation` 的作品版本和 `add-work-generation-task-management` 的运行审计。

## Non-Goals

- 不执行视频生成或任务恢复。
- 不自动发布、不管理平台发布状态或账号凭据。
- 不硬删除有调用事实的作品、版本、任务或素材。
- 不维护金额费用能力。
- 本轮只写 OpenSpec，不执行代码、下载、发布、原型或测试。
