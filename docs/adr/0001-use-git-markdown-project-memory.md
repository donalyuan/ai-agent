# ADR-0001：采用 Git 与 Markdown 项目记忆

- 状态：已接受
- 日期：2026-08-17

## 上下文

当前仓库缺少稳定的项目记忆入口，旧规则指向的记忆文件已不存在。当前树尚不能证实产品架构、技术栈和运行环境，因此需要一个可审计、可由版本控制审查、且不假定额外基础设施的第一阶段方案。

## 决定

采用 Git 跟踪的 Markdown 文档作为第一阶段项目持久记忆：

- `AGENTS.md` 规定读取顺序、事实源优先级、维护和秘密边界。
- `docs/agent/` 按项目事实、长期决策、当前交接和已证实排障信息分类。
- `docs/adr/` 保存长期决策，`DECISIONS.md` 提供简短索引。
- 当前代码、测试、schema 和可执行配置始终优先于记忆文档。

## 取舍

该方案无需额外服务，变更可由 Git 审查并能按文件按需读取；代价是维护依赖任务完成后的人工更新，并不提供语义检索或自动知识抽取。

## 非目标

- 不启用 Basic Memory MCP、向量库、数据库、知识图谱或常驻服务。
- 不创建产品源码、运行时脚手架、依赖配置或用户级配置。
- 不将未经当前仓库验证的历史架构、技术栈或命令写为项目事实。
