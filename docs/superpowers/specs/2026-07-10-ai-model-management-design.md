# AI 模型管理与工作台模型选择设计

## 目标

在 Novex 管理后台统一纳管文本、图片、视频三类模型，并让视频工作台所有现有真实模型调用入口显式选择模型。视频模型本轮只配置，不新增视频生成调用。

## 已确认决策

- 采用统一模型注册表和类型化 provider adapter，不为三类模型复制三套管理逻辑。
- 每个类型最多一个启用默认模型；工作台自动选中默认模型并允许覆盖。
- 一次业务操作选择一个模型，质量闸门、重写和重试均继承该选择。
- 供应商与 API 调用协议分开记录；adapter 只由协议决定，不根据 URL 或模型名称猜测。
- 未引用模型可物理删除，已引用模型只能逻辑删除。
- API Key/API Secret 按用户明确确认原文入库，但任何 API、快照、日志和错误不得返回原文。
- 管理接口按用户明确确认暂不增加认证和权限校验；该决定存在模型路由篡改、额度消耗与服务中断风险。

## DDD

`AIModel` 表示一个可独立调用的模型部署。相同上游模型使用不同地址、协议或凭据时是不同记录。模型类型为 `text`、`image`、`video`；生命周期为 `enabled`、`disabled`、`deleted`。

模型保存供应商、API 调用协议、协议版本、认证方式、请求根地址、上游模型标识、凭据、超时、推理等级、输出限制、类型专属能力、默认状态和最近调用状态。运行和生成任务保存 `model_id` 与不含凭据的实际调用快照。

## BDD

后台“AI 模型管理”使用类型筛选、紧凑表格、行操作和右侧表单抽屉，支持添加、编辑、设为默认、启停和删除。停用默认模型时，有其他启用模型则必须原子指定替代；没有替代时允许关闭该类型能力。

视频工作台在以下位置就近显示模型选择：

- AI 账号策略草稿。
- 选题生成和补充生成。
- 主题组评审。
- 从选题确认生成脚本。
- 脚本 Agent 生成和修改。
- 图片候选批量生成和单分镜重生。

模型被停用后，新请求和待执行图片任务不得调用供应商；已经发出的 HTTP 请求允许自然完成并记录真实结果。

## SDD

PostgreSQL 新增 `ai_models`，扩展 `agent_runs` 与 `asset_generation_tasks`。Rust API 提供 `/api/admin/models` 与 `/api/model-options`，`crates/novex-model` 按显式协议构造文本客户端。Python Worker 按任务 `model_id` 从数据库读取配置并构造图片 provider。

首批协议为 `openai_responses`、`openai_chat_completions`、`openai_images`、`jimeng_visual`、`runway_api`、`kling_api`。一次性导入器把现有环境配置写入数据库，导入只新增、不覆盖；切换后运行时不得回退环境变量。

## TDD

测试覆盖三类 CRUD、字段与协议兼容、默认唯一性、乐观锁、密钥掩码、删除引用规则、工作台全部调用点、同模型内部步骤、停用竞态、Worker 数据库配置、幂等导入和零真实供应商费用。

## 前端设计依据

- 参考 Ant Design 的数据密度、筛选和抽屉表单。
- 参考 IBM Carbon 的表单分组、校验和禁用反馈。
- 参考 GitHub Primer 的状态标签、行操作和低干扰边界。
- 复用根级 `DESIGN.md`；拒绝营销 hero、装饰渐变、嵌套卡片和独立视频生成入口。

正式前端编码前必须新建后台模型管理 Pencil 原型，并更新 `docs/prototypes/video-agent/video-agent.pen` 中全部相关调用页面，完成 Pencil MCP 截图与布局检查并取得用户明确确认。

## 非目标

- 视频生成调用、作品生产和计费验证。
- 自动故障切换、跨模型重试或智能路由。
- 模型成本账单与供应商商务协议。
- 管理员认证、RBAC 和凭据加密。
