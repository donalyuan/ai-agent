# 失败素材任务清理与镜头内容展示设计

## 状态

待用户确认 Pencil 原型后进入开发。本文扩展现有 OpenSpec change `script-to-asset-generation`，不单独创建 change。

## 目标

1. 允许操作者清理失败素材生成任务，页面隐藏噪音但数据库保留完整审计。
2. 在候选素材上方展示当前镜头脚本，明确区分旁白和画面。
3. 清理路径不调用 Worker 或供应商，不产生额外费用。

## 已确认交互

- 左侧分镜列表只展示镜头序号、时长和状态。
- 中间候选区顶部展示“镜头 N 内容 · 时长”，下方为旁白、画面双栏。
- 失败任务卡片使用“清理失败任务”文字操作。
- 点击后必须二次确认；弹窗说明页面隐藏、审计保留和零供应商调用。
- 当前页面不提供恢复入口。

## 数据与 API

在 `asset_generation_tasks` 新增可空 `dismissed_at TIMESTAMPTZ`。清理只写入该字段，不修改 `status=failed`，不删除任务、候选或素材。

新增 `POST /api/asset-generation-tasks/:task_id/dismiss`：

- 仅 `failed` 可清理，其他状态返回 `409 Conflict`。
- 首次写入 `dismissed_at`；重复调用返回原时间，保持幂等。
- 不进入任务队列，不调用 Worker 或供应商。

任务列表默认排除已清理任务。候选列表只排除这些任务关联的 `failed` 候选；部分成功任务已入库的素材及非失败候选继续可见。

当前项目没有可信用户身份上下文，因此不新增无法可靠写入的 `dismissed_by`。统一身份接入后另行补充操作者审计。

## 前端状态

确认提交期间锁定当前任务的清理操作。成功后并行刷新任务与候选；失败时保留原任务卡片和错误，不做乐观隐藏。

镜头内容直接读取已加载的 `Scene.narration` 与 `Scene.visual_description`。即使候选为空也先展示镜头内容；字段为空时显示“未填写旁白”或“未填写画面”，保持双栏尺寸稳定。

## 原型与参考

- Pencil：`docs/prototypes/video-agent/video-agent.pen`
- 主界面节点：`dM5XZ`
- 清理确认节点：`OCAjR`
- 参考系统：Ant Design 的紧凑后台分栏、IBM Carbon 的确认与错误反馈、GitHub Primer 的低干扰边框和文字型危险操作。
- 拒绝：长描述塞入左侧分镜列表、硬删除任务、清理时连带删除成功素材、无确认直接执行。

## 测试边界

- migration 保留历史数据。
- API 覆盖仅失败可清理、重复清理幂等和非失败冲突。
- 仓储覆盖任务/失败候选默认过滤及成功素材保留。
- 前端覆盖确认、重复点击拦截、失败保留和刷新行为。
- 页面覆盖旁白/画面展示、空字段和无候选状态。
- 测试不得开启真实 Worker 或调用供应商。

## 非目标

- 失败任务恢复入口。
- 硬删除或数据库清理作业。
- 在统一身份系统之前记录操作者字段。
