# Source Summary

## Upstream

- Catalog repo: `https://github.com/alexpate/awesome-design-systems`
- Nature: curated directory of public design systems, not a standalone Codex skill package
- Purpose in this project: help design tasks choose credible external references before producing `Pencil MCP` prototypes

## Selection Heuristics For `bigA`

### 1. Data-dense desktop workbench

Use these first when designing watchlists, review workbenches, trading-assistant panels, dense tables, filters, or split-pane layouts:

- `Ant Design`
- `IBM Carbon`
- `GitHub Primer`

Focus on:

- table density and row actions
- filter bars and toolbar hierarchy
- empty/loading/error states
- status badges and semantic color restraint

### 2. Settings, forms, and account flows

Use systems with mature form validation, settings grouping, and operational feedback:

- `Shopify Polaris`
- `IBM Carbon`
- `GitHub Primer`

Focus on:

- field grouping
- validation timing
- destructive-action emphasis
- success/error feedback hierarchy

### 3. Marketing or light landing surfaces

If the task is a lighter landing page or brand section, pair this catalog with `awesome-design-md` and bias toward the `DESIGN.md` source for exact visual tokens. In this case, this catalog is mainly used to compare information architecture, not to define final tokens.

## Required Output In Design Discussions

When this skill is used for a real design task, the design note or prototype discussion should explicitly capture:

1. chosen reference systems
2. patterns to borrow
3. patterns to avoid
4. whether a project-root `DESIGN.md` is needed for this task
