# MVP需求边界

## 核心功能（必做）

### 1. 素材库系统
- [x] 视频/图片/音频上传
- [x] 标签管理（文本数组，不做复杂标签体系）
- [x] Embedding语义检索（Milvus）
- [x] 使用频率统计
- [ ] 版权标记（后置）

### 2. 选题与脚本
- [x] 选题Agent：输入账号定位 → 输出5个选题建议
- [x] 脚本Agent：输入选题 → 输出结构化脚本（分镜/旁白/情绪）
- [x] A/B版本生成（同一选题生成多版本）
- [ ] 爆款内容分析（Month 4）
- [ ] 竞品分析（后置）

### 3. 视频生成
- [x] 对接2个平台：Runway + 可灵
- [x] text-to-video
- [x] image-to-video
- [x] 异步任务队列
- [x] 生成状态查询
- [ ] 质量评分（后置）
- [ ] 失败重试（基础版）

### 4. 发布与分发
- [x] 对接2个平台：抖音 + 小红书
- [x] 手动发布
- [x] 定时发布（基础版）
- [ ] 多账号管理（后置）
- [ ] 格式自动适配（后置）

### 5. 数据回流
- [x] 手动录入基础指标（播放/点赞/评论）
- [ ] 自动爬取（Month 4）
- [ ] 收益统计（后置）

### 6. 爆款分析（Month 4）
- [x] 爬取热门视频
- [x] LLM分析爆款模式
- [x] 生成内容策略建议
- [ ] 自动应用策略到选题Agent（后置）

## MVP不做的功能

### 权限系统
- ❌ 多租户
- ❌ RBAC角色权限
- ❌ 数据权限过滤
- ❌ 用户管理

### 复杂功能
- ❌ 可视化Workflow编排
- ❌ 多Agent协作（只做单Agent链式调用）
- ❌ 人工审批流程
- ❌ 完整的成本核算
- ❌ 详细的Trace可视化（只做基础日志）

### 高级特性
- ❌ 实时数据同步
- ❌ 智能推荐算法
- ❌ 账号矩阵运营
- ❌ AI虚拟人IP系统

## MVP验收标准

### 功能验收
1. 上传10个素材 → 可通过文本搜索匹配
2. 输入"科技博主，讲AI知识" → 生成5个选题
3. 选择1个选题 → 生成完整脚本（至少5个分镜）
4. 提交脚本 → 生成视频（Runway或可灵）
5. 生成的视频 → 发布到抖音和小红书
6. 手动录入数据 → 在Dashboard看到指标

### 技术验收
1. Docker Compose一键启动所有服务
2. API响应时间 < 500ms（非视频生成接口）
3. 向量检索延迟 < 100ms
4. 20个并发任务不出错
5. 数据库查询有索引
6. 关键错误有日志

### 代码质量
1. Rust编译无Warning
2. 数据库迁移可重放
3. 核心Agent有单测
4. API有基础文档

## 开发优先级

### P0（Month 1-2）
- 数据库 + 基础API
- LLM调用层
- 选题Agent + 脚本Agent
- 素材上传 + 检索

### P1（Month 3）
- 视频生成Agent
- Python Worker（Runway + 可灵）
- 发布Agent（抖音 + 小红书）
- 任务队列

### P2（Month 4）
- 爆款分析
- 优化Agent
- 数据Dashboard
- 打磨体验

**Why**: 明确MVP边界，防止过度设计。

**How to apply**:

- 任何不在P0-P2的功能，默认拒绝
